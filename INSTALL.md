# Hisoka GitHub Profile — Version 3

## Installation

1. Open **https://github.com/hisokaBK/hisokaBK**. This must be your special profile repository.
2. Extract this ZIP locally.
3. Copy `README.md` **and the entire `assets/` folder** into the repository root, preserving the folder structure.
4. Commit all files. GitHub renders the README automatically on your profile.

If using Git in PowerShell, inside your local profile repository:

```powershell
git add README.md assets/
git commit -m "Redesign profile: Hisoka Dark Neon V3"
git push
```

## Important details

- No JavaScript or custom HTML/CSS is needed; compatible with GitHub's README renderer.
- The covers under `assets/projects` are **custom stylized illustrations**, **not actual screenshots**. Replace these with real screenshots later if desired; keep the same filenames and links.
- The two Hisoka GIFs from the earlier README are kept as external URLs; their availability depends on Pinterest's image host.
- Stats, typing banner and external badges depend on third-party providers and can temporarily fail.
- Do **not** upload just the `README.md`: it references local GIFs and PNGs in `assets/`.
- GitHub may cache images after a commit; refresh or wait for the cache if a recently edited cover looks outdated.
