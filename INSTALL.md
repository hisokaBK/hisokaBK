# Hisoka GitHub Profile V6 — Installation

## Included in this package
- `README.md`
- `assets/` (banner, developer card, project covers, icons, badge assets)
- `scripts/` (automatic starred repositories badge updater)
- `.github/workflows/` (GitHub Actions workflow)

## Steps
1. Download and extract the ZIP package.
2. Open your GitHub profile repository: `hisokaBK/hisokaBK`.
3. Upload **all files and folders** from the package to the root of the repository.
4. Commit the changes.
5. Go to **Actions** on GitHub.
6. Run the workflow **Update starred repositories badge** once manually.
7. Refresh your profile page.

## Notes
- The README is designed for GitHub profile display.
- Project cover images are clickable and lead to the repositories.
- Decorative images are intended to appear non-clickable as much as possible.
- The starred repositories count is updated automatically by the workflow.
